# Подключение к Telegram

Веб-приложение уже содержит интеграцию с Telegram WebApp API. Конкретный бот ещё не привязан: имя и доступ к боту пользователь не предоставлял.

## Порядок подключения

1. Разместить содержимое `dist/` на общедоступном HTTPS-адресе. Закрытая демонстрация, требующая входа в аккаунт владельца, подходит для просмотра, но не для запуска всеми игроками.
2. Открыть [@BotFather](https://t.me/BotFather), создать бота либо выбрать существующего.
3. Настроить Menu Button: указать текст «Играть» и HTTPS URL приложения. Можно также настроить Main Mini App в профиле бота.
4. Открыть бота в Telegram, нажать «Играть», проверить звук, нажатия, паузу при сворачивании и кнопку «Назад».

Актуальные варианты запуска описаны в [документации Telegram](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button). Настройка меню позволяет запустить этот статический MVP без постоянно работающего собственного bot-сервера.

Токен бота не нужен в браузере. Не добавлять его в `dist/`, JavaScript, URL или Git. При последующем подключении backend токен хранится только в серверных секретах.

## Что делает текущая интеграция

- Сообщает Telegram о готовности и раскрывает доступную область.
- Применяет тёмные цвета и учитывает предоставленные safe-area отступы.
- Показывает BackButton во время партии: он вызывает паузу, на экране результата возвращает к мелодиям.
- Поддерживает вибрацию при попадании/ошибке, если клиент предоставляет API.
- Отключает вертикальные закрывающие свайпы на время игры и включает при выходе.
- При деактивации или скрытии окна останавливает партию.
- Работает в обычном браузере, если Telegram-контекст отсутствует.

Отображаемый инициал пользователя — только оформление. Серверной авторизации и синхронизации прогресса пока нет. Для будущих аккаунтов нужна серверная проверка initData, описанная в архитектуре.

## Проверка на устройстве

На iOS сначала нажать «Играть»: аудиоконтекст запускается по пользовательскому жесту. Проверить также после сворачивания и возврата. На Bluetooth-наушниках возможна задержка: ручная калибровка пока не реализована. В landscape интерфейс доступен, но предпочтительный режим игры — вертикальный.

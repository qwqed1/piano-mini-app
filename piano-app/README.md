# Piano — Telegram Mini App MVP

Работающая ритм-игра: четыре дорожки, три мелодии, синтезированный звук пианино, комбо, три жизни, пауза, результаты и рекорды на устройстве. Управление касанием или D/F/J/K; Esc — пауза. Интерфейс на русском, адаптирован под телефон и компьютер.

## Запуск

Требуется Node.js 22+; сторонние npm-пакеты не нужны.

```sh
cd piano-app
npm run dev
```

Открыть http://127.0.0.1:5173. Каталог `dist/` — **исходные статические файлы**, готовые к размещению на HTTPS-хостинге; генерации и сборки нет. Не удалять его как временный build output.

```sh
npm run check
npm test
```

## Структура

```text
dist/
  index.html      Семантическая оболочка и экраны
  styles.css      Тема, адаптивная вёрстка, состояния
  app.js          Управление интерфейсом, canvas, Telegram-адаптер
  engine.js       Независимые от DOM правила и тайминг
  tracks.js       Каталог, ноты, длительности, дорожки
  audio.js        Web Audio, синтез фортепиано
  storage.js      Проверка и сохранение локальных рекордов
scripts/serve.mjs Локальный статический сервер
tests/           Проверки игрового движка и сохранений
docs/            Архитектура, запуск в Telegram, QA
```

MVP не включает кошельки, вывод средств, Stars, донаты, персонажа или серверные аккаунты. Очки — результат игры; они не являются деньгами. Игра не обращается к Bot API и не содержит токена бота. Telegram-профиль используется только для отображения инициала.

Сведения о пользователе, полученные в браузере, не считаются подтверждённой авторизацией. Рекорды локальны, не синхронизируются между устройствами и не защищены от изменения игроком.

Музыка: самостоятельно закодированные короткие одноголосные аранжировки старинных мелодий; сторонние звукозаписи не используются. Звук генерируется Web Audio. Шрифт Manrope загружается с Google Fonts, с локальным fallback. Telegram SDK загружается с telegram.org; обычный браузер поддерживается без Telegram.
